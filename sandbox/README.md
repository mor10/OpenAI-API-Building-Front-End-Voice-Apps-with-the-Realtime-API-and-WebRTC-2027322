# OpenAI Realtime API Demo

Next.js app demonstrating OpenAI's Realtime API with voice chat.

## Setup

1. Set `OPENAI_API_KEY` in `../auth-server/.env`
2. Start auth server: `cd ../auth-server && node server.js`
3. Install dependencies: `npm install`
4. Run app: `npm run dev`

Visit `http://localhost:9307`
